AI Crypto Trader - PWA v0.1

محتويات النسخة:
- واجهة عربية قابلة للتثبيت كتطبيق PWA.
- اختيار رمز من قائمة عملات USDT-M Futures.
- جلب سعر وبيانات شموع عامة من Binance Futures API.
- تحليل أولي باستخدام EMA 9/21 و RSI 14 و ATR 14.
- حساب وقف الخسارة والأهداف وحجم المركز وفق مخاطرة 1%.
- لا يوجد ربط بحساب المستخدم ولا تنفيذ أوامر تداول.

طريقة التجربة:
1) فك ضغط الملف.
2) ارفع محتويات المجلد إلى استضافة HTTPS ثابتة مثل GitHub Pages أو Netlify.
3) افتح رابط HTTPS في Chrome على Android.
4) من قائمة Chrome اختر "تثبيت التطبيق" أو "إضافة إلى الشاشة الرئيسية".

ملاحظات:
- ملف service worker يحتاج HTTPS (أو localhost).
- بيانات Binance عامة فقط؛ قد لا تعمل بعض الشبكات أو المتصفحات بسبب قيود الاتصال/CORS.
- هذه نسخة نموذج أولي، لا تستخدمها لاتخاذ قرار تداول حقيقي.
- حساب الكمية تقريبي، ولا يأخذ في الحسبان دقة الكمية/السعر، الحد الأدنى للأمر، الرسوم، التمويل، الانزلاق، الرافعة أو قواعد الهامش.
- قبل أي استخدام فعلي يجب إضافة اختبار تاريخي، اختبار أمامي تجريبي، إدارة أخطاء، والتحقق من قواعد كل عقد.
- لا تضع API Secret أو مفاتيح تسمح بالتداول/السحب في واجهة المتصفح.
